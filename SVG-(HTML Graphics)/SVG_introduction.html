SVG Introduction

  • SVG stands for Scalable Vector Graphic is a XML language used to make graphics and animations like in HTML canvas. It is a type of vector graphic that may be scaled up or down. SVG is a web standard for vector-based graphics. It is an XML format that defines graphics.
  • In SVG files, every element and property can be animated. SVG is compatible with other W3C standards such as the Document Object Model (DOM) and XSL.

How SVG Integrates with HTML?

  • Inline SVG :- Embed SVG directly within HTML using the <svg> element.
  • External SVG :- Link to an external SVG file using the <object> or >img< element.
  • Inline SVG with <use> :- Reuse SVG elements within HTML using the <use> element.
  • JavaScript Manipulation :- Dynamically create or modify SVG elements using JavaScript.

SVG Basic Examples :-

using Inline SVG element drawing a Circle

  • cx="50": Sets the x-coordinate of the circle's center to 50 units.
  • cy="50": Sets the y-coordinate of the circle's center to 50 units.
  • r="40": Sets the radius of the circle to 40 units.
  • fill="red": Sets the fill color of the circle to red.

If Circle measurements exceeds SVG width and height then it won't form full circle this is an example



using Inline SVG element drawing a Line

  • x1="10": Sets the x-coordinate of the line's starting point to 10 units.
  • y1="10": Sets the y-coordinate of the line's starting point to 10 units.
  • x2="450": Sets the x-coordinate of the line's ending point to 450 units.
  • y2="450": Sets the y-coordinate of the line's ending point to 450 units.
  • stroke:brown: Sets the stroke (color) of the line to brown
  • stroke-width:5: Sets the width of the line to 5 units.

using Inline SVG element drawing a Rectangle


using Inline SVG element drawing a Rounded Rectangle

  • x="80": Sets the x-coordinate of the rectangle's upper-left corner to 80 units.
  • y="20": Sets the y-coordinate of the rectangle's upper-left corner to 20 units.
  • rx="20" and ry="20": These attributes define the radius of the rectangle's corners, giving it rounded corners with a radius of 20 units.
  • width="210": Sets the width of the rectangle to 210 units.
  • height="150": Sets the height of the rectangle to 150 units.

using Inline SVG element drawing a Star


  • points="100,10 40,198 190,78 10,78 160,198": Specifies the coordinates of the vertices of the polygon. These points create a star-like shape.
  • fill-rule: evenodd: Specifies the rule used to determine the inside of the shape. The evenodd rule alternates between filling and not filling areas, based on the number of polygon edges crossed.

using Inline SVG element drawing a Logo

  • <defs>:This tag is used to define reusable elements within the SVG. Any elements inside <defs> can be referenced elsewhere in the SVG.
  • linearGradient id="grad1" x1="0%" y1="0%" x2="100%" y2="0%"
    • This defines a linear gradient with the ID grad1
    • x1="0%" y1="0%": Sets the starting point of the gradient at the top-left corner.
    • x2="100%" y2="0%": Sets the ending point of the gradient at the top-right corner.
  • stop offset="0%" style="stop-color:white; stop-opacity: 1
    • This defines the first color stop in the gradient
    • offset="0%": The stop is placed at the starting point of the gradient.
    • style="stop-color:white; stop-opacity: 1": The color at this stop is white with full opacity.
  • stop offset="100%" style="stop-color: green; stop-opacity: 1
    • This defines the second color stop in the gradient
    • offset="100%": The stop is placed at the ending point of the gradient.
    • style="stop-color: green; stop-opacity: 1": The color at this stop is green with full opacity.
  • ellipse cx="200" cy="100" rx="120" ry="80" fill="url(#grad1)"
    • This defines an ellipse (oval shape) inside the SVG container
    • cx="200": Sets the x-coordinate of the center of the ellipse to 200 units.
    • cy="100": Sets the y-coordinate of the center of the ellipse to 100 units.
    • rx="120": Sets the horizontal radius of the ellipse to 120 units.
    • ry="80": Sets the vertical radius of the ellipse to 80 units.
    • fill="url(#grad1)": Fills the ellipse with the linear gradient defined by grad1
  • text fill="#ffffff" font-size="22" font-family="ARIAL" x="120" y="110"
    • This defines a text element inside the SVG container.
    • fill="#ffffff": Sets the fill color of the text to white.
    • font-size="22": Sets the font size of the text to 22 units.
    • font-family="ARIAL": Sets the font family of the text to Arial.
    • x="120": Sets the x-coordinate of the starting point of the text to 120 units.
    • y="110": Sets the y-coordinate of the starting point of the text to 110 units.
