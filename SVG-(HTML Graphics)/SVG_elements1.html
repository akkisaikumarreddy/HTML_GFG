SVG <a> Element

Syntax :

<a href=""
target=""
type=""
rel=""
download="">
</a>


  • href:- It stands for hypertext reference and takes the link to the other documents.
  • download:- It instructs the browser to download a file.
  • hreflang:- It is the human language of the URL or in simple words the URL fragment that hyperlink point is the hreflang.
  • rel:- It tells the relationship between the target and source documents.
  • target:- It tells about where the webpage is to be displayed.

SVG <animate> Element

Syntax :

<animate attributeName="" values="" dur="" repeatCount="" />


The <animate> SVG element is used to animate an attribute or property of an element over time. It’s normally inserted inside the element which we want to animate.

  • <svg viewBox="0 0 50 50">: Defines an SVG (Scalable Vector Graphics) container with a view box of 50x50 units. This element creates an area where the SVG graphics will be drawn.
    • The viewBox is an attribute of the SVG element in HTML. It is used to scale the SVG element that means we can set the coordinates as well as width and height.
    • Syntax:viewBox = "min-x min-y width height"
    • min-x is used to set the horizontal axis. It is used to make the SVG move on a horizontal axis (i.e Left and Right).
    • min-y is used to set the vertical axis. It is used to make the SVG move on a vertical axis (i.e Up and Down).
    • width is used to set the width of viewbox.
    • height is used to set the height of viewbox
  • <rect width="10" height="10" fill="green">: This creates a rectangle with a width and height of 10 units, filled with the color green.
  • <animate attributeName="rx" values="0;20;0" dur="2s" repeatCount="10" />: This tag animates the rectangle by altering its rx attribute
    • attributeName="rx": Specifies the attribute to animate, in this case, rx (corner radius of the rectangle).
    • values="0;20;0": Defines the animation values in a sequence (from 0 to 20 and back to 0).
    • dur="2s": Specifies the duration of the animation (2 seconds).
    • repeatCount="10": Defines how many times the animation should repeat (10 times).
  • attributeName="opacity": The attribute to animate is the opacity of the rectangle.
  • from="1": The animation starts with an opacity of 1 (fully opaque).
  • to="0": The animation transitions to an opacity of 0 (fully transparent).

SVG <animateMotion> Element

Syntax :

<animateMotion values="" dur="" repeatCount="" path="" />


The SVG <animateMotion> element let define how an element moves along a motion path.

  • path="M20, 60 C20, -50 180, 150 180, 60 C180-60 20, 150 20, 60 z": Defines the path for the animation using a series of commands:
    • M20, 60 : Move to the starting point (20, 60)
    • C20, -50 180, 150 180, 70 : Create a cubic Bézier curve from (20, 70) to (180, 60) with control points (20, -50) and (180, 150).
    • C180-60 20, 150 20, 70 : Another cubic Bézier curve from (180, 70) to (20, 60) with control points (180, -60) and (20, 150).
    • z: Close the path, returning to the starting point (20, 60).

SVG <animateTransform> Element

Syntax :

<animateTransform attributeName=''transform''/>

  • The animateTransform element animates a transformation attribute on its target element, thereby allowing animations to control translation, scaling, rotation, and/or skewing
    • from: Initial value of the attribute that will be modified during the animation.
    • to: Final value of the attribute that will be modified during the animation.
    • type: It defines the type of transformation, whose values change over time.
    • dur: Duration of the animation.
    • repeatCount: The number of times an animation will take place.
    • repeatDur: The total duration for repeating an animation.
    • attributeName: The name of the CSS property that is going to be animated.

  • <polygon points="60,30 90,90 30,90">: This creates a polygon (triangle) with the vertices at points (60,30), (90,90), and (30,90). This defines a shape with three sides.
  • attributeName="transform": Specifies that the attribute being animated is the transform attribute.
  • attributeType="XML": Indicates that the attribute is part of the XML namespace.
  • type="rotate": Specifies the type of transformation, which is a rotation.
  • from="0 60 70": The animation starts with the polygon at 0 degrees rotation, with the rotation axis at (60, 70).
  • to="360 60 70": The animation rotates the polygon to 360 degrees, with the same rotation axis at (60, 70).
  • dur="10s": Specifies the duration of the animation (10 seconds).
  • repeatCount="indefinite": Specifies that the animation should repeat indefinitely.
